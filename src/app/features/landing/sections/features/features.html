Explorer suppose de contribuer

Le module d'exploration s'appuie sur une base commune : les données des différentes instances de Cicada sont centralisées sur le serveur de Réserves naturelles de France. Y accéder suppose donc d'y contribuer — le partage de vos propres données conditionne l'accès à cette fonctionnalité, et relève d'un consentement explicite de votre structure lors du déploiement d'une instance.
