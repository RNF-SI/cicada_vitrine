Déployer CICADA

Deux manières d'y venir

CICADA est un logiciel libre : vous pouvez l'installer sur vos propres serveurs, ou demander à bénéficier de la plateforme hébergée par le projet. Les deux voies donnent accès aux mêmes fonctionnalités — seule la charge d'exploitation change.

Option 1

J'installe CICADA moi-même

Le code est public et la pile complète se lance par Docker Compose. Adapté aux structures qui disposent d'une équipe technique et qui souhaitent garder la main sur leur hébergement.
